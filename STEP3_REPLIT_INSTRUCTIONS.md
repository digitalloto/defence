# STEP 3 — HOW TO PUT THIS ON REPLIT (Simple Numbered Steps)

## What You're Building
A professional-looking interactive web page that shows:
- Vision 2047 priorities on one side
- How AIMCRS addresses each one on the other side
- Click any priority to see full details
- Looks clean and professional for defence contacts

## What the 3 Files Do (Simple Explanation)
- **index.html** = The structure of the page (like the skeleton of a building)
- **style.css** = How it looks (colours, fonts, spacing — like the paint and decoration)
- **script.js** = How it behaves (what happens when you click things — like the electricity)

---

## STEP-BY-STEP INSTRUCTIONS

### Step 1: Go to Replit
1. Open your browser (Chrome, Safari, etc.)
2. Go to: **replit.com**
3. Log in (or create a free account if you don't have one)

### Step 2: Create a New Project
1. Click the blue **"+ Create Repl"** button (top left)
2. In the template search, type: **HTML, CSS, JS**
3. Select the template called **"HTML, CSS, JS"**
4. In the "Title" field, type: **AIMCRS-Vision-2047**
5. Click **"Create Repl"**

### Step 3: You'll See 3 Files Already Created
Replit will show you 3 files on the left side:
- `index.html`
- `style.css`
- `script.js`

These are the same 3 files we've created. You need to replace their contents.

### Step 4: Paste the HTML File
1. Click on **index.html** in the left panel
2. Select ALL the text in the editor (Ctrl+A on Windows, Cmd+A on Mac)
3. Delete it (press Delete or Backspace)
4. Open the file **index.html** from this repository
5. Copy ALL the text (Ctrl+A then Ctrl+C)
6. Paste it into Replit (Ctrl+V)

### Step 5: Paste the CSS File
1. Click on **style.css** in the left panel
2. Select ALL the text (Ctrl+A)
3. Delete it
4. Open the file **style.css** from this repository
5. Copy ALL the text (Ctrl+A then Ctrl+C)
6. Paste it into Replit (Ctrl+V)

### Step 6: Paste the JavaScript File
1. Click on **script.js** in the left panel
2. Select ALL the text (Ctrl+A)
3. Delete it
4. Open the file **script.js** from this repository
5. Copy ALL the text (Ctrl+A then Ctrl+C)
6. Paste it into Replit (Ctrl+V)

### Step 7: Run It
1. Click the big green **"Run"** button at the top
2. A preview window will appear on the right side showing your web page
3. That's it! Your page is live.

### Step 8: Get the Link to Share
1. In the preview window (right side), you'll see a URL at the top
2. It will look something like: `https://aimcrs-vision-2047.yourusername.repl.co`
3. Click the **"Open in new tab"** button (small arrow icon)
4. Copy that URL — this is what you share with defence contacts

---

## TROUBLESHOOTING

**Problem:** Page looks blank or broken
**Fix:** Make sure you pasted the COMPLETE file contents. Even one missing character can break it.

**Problem:** Can't find the Run button
**Fix:** Look at the very top of the Replit screen. The green "Run" button is in the centre.

**Problem:** Preview doesn't show
**Fix:** Click the small "Output" tab at the bottom of the screen.

## HOW TO CUSTOMISE

### To change patent descriptions:
1. Open **script.js**
2. Search for "patent" (use Ctrl+F)
3. You'll find the 3 patent descriptions in the HTML file (index.html)
4. Change the text to match your actual patent titles and numbers

### To add your contact details:
1. Open **index.html**
2. Search for "Abheet Prem Manghnani"
3. Add your phone number and email where needed

### To add your company logo:
1. Upload your logo image to Replit (drag and drop into the files panel)
2. In **index.html**, find the line with `class="logo-icon"`
3. Replace `◆` with `<img src="your-logo.png" alt="AIMCRS" style="height: 40px;">`
