# Data Sources — License and Usage Guide

## Important: Copyright and Usage Rules

All data collected by this pipeline must follow these rules:

1. **Creative Commons videos** — Safe to use for training
2. **Standard YouTube videos** — Research use ONLY, never redistribute
3. **Government open data** — Free to use (Open Government Data License India)
4. **Academic datasets** — Follow each dataset's specific license
5. **Kaggle datasets** — Follow each dataset's specific license
6. **Roboflow datasets** — Follow each dataset's specific license

---

## Source Details

### YouTube (via yt-dlp)

- **Tool:** yt-dlp (free, open source)
- **License:** Each video has its own license
- **Our rule:** Flag each video as Creative Commons or Standard
- **Creative Commons:** Safe for training
- **Standard:** Research use only — do not redistribute

### data.gov.in

- **License:** Open Government Data License India
- **Usage:** Free to use, share, and build upon
- **URL:** https://data.gov.in

### Smart Cities Mission

- **License:** Government of India open data
- **Usage:** Free to use
- **URL:** https://smartcities.gov.in

### MoRTH Reports

- **License:** Government publications — public domain
- **Usage:** Free to use and cite
- **URL:** https://morth.nic.in

### NCRB Data

- **License:** Government publications — public domain
- **Usage:** Free to use and cite
- **URL:** https://ncrb.gov.in

### IDD (India Driving Dataset)

- **License:** Academic research license
- **Usage:** Free for research — check terms for commercial use
- **URL:** https://idd.insaan.iiit.ac.in

### UA-DETRAC

- **License:** Academic research license
- **Usage:** Free for research
- **URL:** https://detrac.smu.edu.sg

### Kaggle Datasets

- **License:** Varies per dataset — check each one
- **Usage:** Most are CC0 or CC-BY — check before using commercially

### Roboflow Universe

- **License:** Varies per dataset — check each one
- **Usage:** Most are CC-BY or open — check before using commercially

### TomTom Traffic API

- **License:** Commercial API with free tier
- **Free tier:** 2,500 requests/day
- **URL:** https://developer.tomtom.com

### HERE Maps API

- **License:** Commercial API with free tier
- **Free tier:** 250,000 requests/month
- **URL:** https://developer.here.com

### MapMyIndia / Mappls

- **License:** Commercial API with free tier
- **URL:** https://maps.mapmyindia.com

### OpenStreetMap

- **License:** Open Database License (ODbL)
- **Usage:** Free to use — must give credit
- **URL:** https://www.openstreetmap.org
